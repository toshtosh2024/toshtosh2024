### 🚀 Projects & Competitions

**🩻 Medical Image Analysis | RSNA Knee**

Developing deep learning pipelines for knee MRI classification using CNN-based architectures, including RadNet, ConvNeXt, and CoAtNet.

- Achieved an out-of-fold AUC of approximately **0.944**
- Investigated generalization gaps, missing imaging slices, and inference robustness

**🤖 LLM Attribution | Name That LLM**

Exploring whether language models can be identified from their generated text.

- Combining stylistic features, TF-IDF, LinearSVC, and LightGBM
- Experimenting with Qwen-based LoRA fine-tuning and ensemble methods
- Investigating model-specific writing patterns and potential data leakage

**🧪 Molecular Structure Identification | CASMI**

Working on molecular structure identification from mass spectrometry data.

- Exploring candidate generation and molecular ranking
- Improving candidate recall and evaluating chemical consistency

**🚢 Maritime Data Analysis | AIS**

Analyzing vessel movements and predicting passage through the Strait of Hormuz.

- Working with vessel attributes and AIS data
- Emphasizing robust validation and leakage-aware feature engineering

### 🚀 主なプロジェクト

**🩻 医療画像解析 | RSNA Knee**

MRI画像を用いた分類モデルの開発に取り組んでいます。

RadNet、ConvNeXt、CoAtNetなどを活用し、OOF AUC約0.944を達成。推論時の欠損や汎化性能の検証も行っています。

**🤖 LLMの識別 | Name That LLM**

生成された文章から、その文章を出力したLLMを推定する課題に取り組んでいます。

TF-IDF、LinearSVC、LightGBM、QwenのLoRAファインチューニングなどを組み合わせ、モデル固有の文体的特徴を分析しています。

**🧪 分子構造推定 | CASMI**

質量分析データから分子構造を推定する課題に取り組んでいます。候補分子の生成、候補再現率の改善、ランキング手法を検討しています。

**🚢 船舶データ解析 | AIS**

AISデータを用いた船舶の行動分析・ホルムズ海峡の通過予測に取り組んでいます。データリークを防いだ特徴量設計や評価を重視しています。
